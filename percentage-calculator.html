关于百分比计算器

百分比是日常生活里最容易算错的一类数字：打折、工资涨幅、考试正确率、销售额占比、利息变化，背后其实是不同的公式。本页把三种最常见的需求放在一起，输入数字就会实时出结果，不需要记公式。第一个模块回答“X 是 Y 的百分之几”，例如 25 是 200 的 12.5%；第二个模块回答“从原值变到新值，涨了或跌了百分之几”；第三个模块回答“原值增加或减少某个百分比之后是多少”，会同时给出增加后和减少后的两个数值。所有输入都会做检查，空值、非数字、除数为 0 都会明确提示，不会显示占位假数据。

三个模块各自的口径

求占比的公式是 X ÷ Y × 100%，这里的 Y 是总量或基准，X 是其中的一部分，结果可能超过 100%，说明 X 比 Y 还大，这并不算错误。涨跌幅的公式是（新值 − 原值）÷ 原值 × 100%，正数代表上涨，负数代表下跌，分母必须是变化前的原值，因为我们要衡量的是“相对原来变化了多少”。增减百分比模块则以原值为基数，增加后的结果等于原值 ×（1 + 百分比 ÷ 100），减少后的结果等于原值 ×（1 − 百分比 ÷ 100），百分比填负数时会自动反向。举例来说，200 增加 15% 是 230，减少 15% 是 170，一增一减并不回到 200，这是百分比计算的常见陷阱。

常见误区与使用建议

第一，不要把“百分比”和“百分点”混为一谈：从 5% 涨到 8%，可以说涨了 3 个百分点，也可以说相对上涨了 60%，两种说法含义不同。第二，涨跌幅不可逆：下跌 50% 后需要上涨 100% 才能回到原点，所以用涨跌幅比较风险时要注意基数已经变了。第三，多个百分比不能直接相加，尤其是基于不同基数的占比。第四，财务、统计等正式场景对四舍五入位数有要求，本页默认保留两位小数并去掉多余的零，需要更精确的结果时请以原始数据自行复算。

常见问题

涨跌幅的分母是原值还是新值？

涨跌幅的通用算法是以原值（变化前的数值）为分母，即（新值减原值）除以原值再乘百分之百。以新值为分母会得到不同的数，比较时容易出错。

为什么原值为 0 时无法计算涨跌幅？

涨跌幅要除以原值，原值为 0 时分母为 0，结果没有数学意义。此时只能描述变化量，不能描述变化率。

百分比和百分点有什么区别？

从 5% 上升到 8%，可以说是上升了 3 个百分点，也可以说相对上升了 60%。前者是两个百分数直接相减，后者是变化量除以原百分数，两者不能混用。
